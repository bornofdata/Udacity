# Future AWS AI Programmer Nanodegree

## Overview

The Future AWS AI Programmer Nanodegree is a structured learning program designed to build practical programming and artificial intelligence skills from the ground up. The course begins with Python fundamentals, progresses through data analysis tools, introduces neural networks, and concludes with transformer-based deep learning applications.

This program is intended for learners who want to develop a strong foundation in AI programming by combining coding, data handling, model understanding, and project-based practice. Rather than focusing only on theory, the program emphasizes hands-on implementation and real-world workflows commonly used in AI and machine learning.

---

## Program Goals

By completing this Nanodegree, learners are expected to:

- Build confidence using Python for AI-related tasks
- Understand and apply core programming concepts such as functions, control flow, data structures, and object-oriented programming
- Work with common data science libraries including NumPy, Pandas, Matplotlib, and Seaborn
- Understand the foundations of neural networks and model training
- Use PyTorch to implement deep learning workflows
- Understand the basics of transformer architectures and pre-trained transformer models
- Complete practical projects that demonstrate applied AI programming skills

## Featured Project: Using a Pre-trained Image Classifier to Identify Dog Breeds

### Project Purpose

This project is designed to help learners practice Python programming in the context of an AI application. Learners use a provided image classifier to determine whether pet images are dogs or not dogs, compare predicted labels with expected labels, and evaluate the performance of different CNN architectures.

### Important Clarification

A key part of this project is that the image classifier is already provided. Learners are not required to build or train the classifier. Instead, they are expected to write the Python code that:
- prepares the data
- calls the classifier
- compares labels
- determines whether labels correspond to dogs
- calculates statistics
- reports final results

### Project Objectives

The project has two main technical objectives:

1. Correctly identify which pet images are of dogs and which are not dogs
2. Correctly classify the breed of dog for images that are dogs

A third practical objective is to compare the trade-off between:
- classification accuracy
- runtime performance

### Models Considered

The project compares three CNN architectures:
- AlexNet
- VGG
- ResNet

The goal is to determine which model performs best for the task and whether a faster model may still be good enough depending on the use case.

### Core Programming Tasks

Learners complete the following tasks:
- Measure program runtime
- Accept user input through command line arguments
- Create pet image labels from filenames
- Store labels in a dictionary-based data structure
- Use the provided classifier function to generate classifier labels
- Compare classifier labels with pet labels
- Determine whether each label is a dog or not a dog using `dognames.txt`
- Calculate summary statistics
- Print formatted results

### Key Learning Outcomes from the Project

By completing this project, learners strengthen their ability to:
- work with files and filenames
- use dictionaries and lists together in compound data structures
- process and compare strings carefully
- organize a multi-step Python program
- evaluate outputs from an AI system
- think critically about performance and accuracy trade-offs

## Final Reflection

The Future AWS AI Programmer Nanodegree provides a guided path from Python basics to modern AI applications. It helps learners build confidence not only in writing code, but also in understanding how AI tools are used, evaluated, and improved in practice.

A major strength of the program is that it teaches learners to work around AI models as well as with them. In the dog breed classification project, for example, the learner’s task is not to invent the classifier, but to build the logic that makes the classifier useful in a real workflow. This reflects an important real-world skill: many AI practitioners spend as much time preparing inputs, validating outputs, measuring performance, and communicating results as they do building models themselves.

Overall, this Nanodegree serves as a strong entry point into AI programming and prepares learners for more advanced study and project work in machine learning, deep learning, and applied artificial intelligence.
